Evidence Navigation and Verification Guide

This free guide helps you locate and examine material that is already public. It does not create new claims, rewrite existing documents, or restrict access to the record.

1. Start with original documents

Prefer the underlying PDFs, correspondence and official records over narrative summaries. The rebuild site and the companion Barran Dodger archive both link to source files.

2. Understand the distinctions used in the archive

  • Documented record / official correspondence — what was written or sent.
  • First-person account — what the author states occurred or was experienced.
  • Allegation — a claim that has not been adjudicated.
  • Interpretation — meaning drawn from the material.
  • Unresolved — matters the available record does not settle.

These categories are not interchangeable. A link is not a finding.

3. Hashes and OpenTimestamps

A SHA-256 hash and an OpenTimestamps receipt can show that a particular file has not changed since it was stamped. They do not prove authorship, accuracy, or the truth of the contents. Always compare the receipt against the file you actually downloaded.

4. Practical steps

  1. Open the relevant PDF or HTML page from the archive.
  2. Note any printed hash or .ots link.
  3. Download the file and, if you wish, verify the hash independently.
  4. Read the document itself rather than relying only on surrounding commentary.

This guide is additive and can be removed without affecting any existing page or document. Primary evidence remains free.
