# Monetisation configuration

File: monetization.json

Public URLs only. Do not put API keys, AdSense secrets, or Stripe secret keys in this file or in the repository.

| Switch | State |
| --- | --- |
| donations | On. Card gifts use the public Stripe donation links. PayID and bank details were already printed on the site. |
| monthly_support | On. A$10 a month, public Stripe link. Cancel from the Stripe receipt. |
| publications / store_url | Points at the church publications shelf. The documentary archive is not for sale. |
| memberships | Off. No exclusive file exists, so no paid tier is honest yet. |
| advertising | Off. |
| newsletter | Off. |
| analytics | Off. Do not invent popularity. |
| sponsorship_contact | Empty. |

The chosen-amount Stripe link has a minimum of A$2 set in Stripe. Contributions are not described as tax deductible.
