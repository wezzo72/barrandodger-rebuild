Forensic Integrity Fortification Certificate

Finding aid. Not a court. Not a verdict. A link is not a finding. Cryptographic methods establish continuity and integrity of digital records, not the truth of their contents.

Purpose

This page fortifies the Barran Dodger / Dr Richard William McLean documentary archive with explicit, independent verification pathways. It adds forensic, intellectual, and legal robustness by documenting methods that any reader can use to confirm completeness, integrity, and provenance without relying solely on the site's presentation.

Existing Integrity Mechanisms

  • Git history on GitHub provides immutable commit timeline for all files.
  • SHA-256 hashes published for key documents (see individual pages and stamps).
  • OpenTimestamps (.ots) receipts for selected files, anchoring to Bitcoin blockchain for temporal proof.
  • GitHub Actions workflows: verify-archive.yml checks the 660-page preservation manifest integrity; seal-reach.yml appends daily reach readings.
  • Publication inventory and source maps in data/ and PUBLICATION-INVENTORY.md.

Independent Verification Steps (Any Reader)

  1. Clone the repository: git clone https://github.com/wezzo72/barrandodger-rebuild.git
  2. Verify key file hashes against published SHA-256 values using sha256sum or equivalent.
  3. For .ots files, use OpenTimestamps tools to confirm blockchain anchoring: ots verify file.pdf.ots
  4. Inspect Git log for commit history and authorship continuity: git log --oneline
  5. Review the verify-archive workflow results on GitHub Actions for the 660-record preservation copy.
  6. Cross-reference official government documents against primary sources where available.

Completeness Statement

The rebuild archive is derived from a 660-page preservation copy of barrandodger.com, with HTML, PDF, and links records matching the manifest. Additional documents, statements, legal briefs, and gospels have been added with timestamps. The full corpus spans multiple related repositories (see PUBLICATION-INVENTORY.md). This page does not claim absolute completeness of all historical material, but documents the current preserved state as of the last commit.

Legal and Intellectual Fortification

  • All material is presented as a public documentary record for independent examination.
  • Distinctions between documented fact, official record, first-person account, allegation, inference, and unresolved matter are maintained.
  • Cryptographic proofs support non-repudiation of the digital versions as of their stamping dates.
